# 调试技巧

## 常用命令

```bash
# 查进程
ps -ef | grep -E 'kwin|plasmalogin' | grep -v grep

# 查 portal 接口
gdbus introspect --session --dest org.freedesktop.portal.Desktop \
    --object-path /org/freedesktop/portal/desktop | grep -i screencast

# 查 KMS 抓取
tail -f ~/.config/sunshine/sunshine.log | grep -i 'mapped\|monitor'

# 查 systemd 服务
systemctl --user status <service>
journalctl --user -u <service> --since "10 minutes ago"

# 查显示器状态
for d in /sys/class/drm/card*/edid; do
    name=$(basename $(dirname $d))
    echo "$name: enabled=$(cat /sys/class/drm/${name}/enabled)"
done

# 查 D-Bus 服务
qdbus6 <service> <path>

# 查环境变量
cat /proc/<PID>/environ | tr '\0' '\n' | grep proxy

# 查 core dump
coredumpctl info <pid>
```

## 日志位置

- Sunshine: `~/.config/sunshine/sunshine.log`
- KWin: `journalctl -b | grep kwin`
- Portal: `journalctl -b | grep portal`
- KScreen: `journalctl -b | grep kscreen`
